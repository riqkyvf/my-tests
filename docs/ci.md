# CI и отчёты

[← README](../README.md)

## Запуск

Workflow [PomidorQA tests](../.github/workflows/tests.yml) выполняется в GitHub Actions
при push и pull request в `main`. Для ручного запуска откройте
**Actions → PomidorQA tests → Run workflow**.

| Режим | Проверки | Запуск |
| --- | --- | --- |
| `smoke` | Три сценария: регистрация, вход и бронирование | Автоматически и по умолчанию при ручном запуске |
| `full` | Полный набор из 78 случаев | По выбору при ручном запуске |

## Проверки CI

Сначала выполняются линтинг и проверка форматирования Ruff, затем выбранный набор
тестов в Chromium. Окружение: Ubuntu 24.04, Python 3.14 и Node.js 24 для Allure.

После первого падения тест запускается повторно. Успешная вторая попытка
засчитывается как пройденный тест; повторное падение завершает шаг тестов с ошибкой.
Обе попытки сохраняются в Allure.

## Отчёты и диагностика

Артефакты доступны в разделе **Artifacts** завершённого запуска и хранятся семь дней.

| Артефакт | Содержимое |
| --- | --- |
| `allure-report` | HTML-отчёт с результатами и шагами тестов |
| `allure-results` | Исходные результаты для генерации Allure-отчёта |
| `playwright-diagnostics` | Trace и скриншоты неуспешных попыток, включая попытки перед успешным повтором |

Чтобы открыть отчёт, скачайте и распакуйте `allure-report`, затем откройте
`index.html` в браузере.

Результаты и диагностика сохраняются и при падении тестов. `allure-report`
доступен после успешной генерации HTML, `playwright-diagnostics` — при наличии
неуспешных попыток. Trace и скриншоты хранятся отдельно от HTML-отчёта.
